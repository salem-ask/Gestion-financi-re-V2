# Captures WhatsApp — preuves sociales

5 captures réelles sont en place : `whatsapp-01.jpg` à `whatsapp-05.jpg`.
Numéro de téléphone et photo de profil sont floutés directement sur chaque
image ; le reste de la conversation est affiché tel quel, sans recadrage.

Pour ajouter une capture supplémentaire, déposez-la ici sous le nom
`whatsapp-06.jpg` (etc.) après avoir flouté tout numéro de téléphone, photo
de profil ou nom complet identifiable, puis dupliquez un bloc
`<figure class="proof-card">` dans `../../index.html` — voir
`../../README.md` pour le détail. Tant qu'un fichier référencé est absent,
la page affiche automatiquement un encadré « Capture WhatsApp à venir » à sa
place.
